# Fotos da galeria

Coloque nesta pasta as imagens exportadas ou sincronizadas do Google Drive.

Formatos aceitos: `.avif`, `.jpg`, `.jpeg`, `.png` e `.webp`.

Arquivos `.HEIC` recebidos do Drive devem ser convertidos para WebP antes da publicação. Os HEICs originais ficam preservados localmente e ignorados pelo Git.

O site descobre os arquivos automaticamente no próximo build. Use nomes descritivos, pois o nome do arquivo também será usado como texto alternativo. Para controlar a ordem, comece com números:

```text
01-encontro-em-jacarepagua.webp
02-agenda-com-liderancas.jpg
```
